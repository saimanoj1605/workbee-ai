# WorkBee

A full-stack application for gig work management.

## Project Structure

```
workbee/
├── frontend/        # React/Next.js frontend application
├── backend/         # Express.js backend API with Prisma ORM
├── docs/           # Project documentation
├── README.md       # This file
├── .gitignore      # Git ignore rules
└── package.json    # Root package configuration
```

## Getting Started

### Backend Setup
```bash
cd backend
npm run setup:dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

## Tech Stack

- **Frontend**: React/Next.js
- **Backend**: Express.js with TypeScript
- **Database**: PostgreSQL (via Neon or local)
- **ORM**: Prisma

## Database

Set up your `.env` file in the `backend` directory with your database connection string.
